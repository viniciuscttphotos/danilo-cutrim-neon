# BRAZA — Baile Cítrico Utrópico Lunar

Landing page de pré-save criada a partir do post oficial do BRAZA.

## Atualizar os links de streaming

Edite o objeto `STREAMING_LINKS` no início de `script.js` quando as URLs oficiais do álbum forem liberadas:

- `spotify`
- `apple`
- `deezer`

Até lá, os botões levam aos perfis oficiais/localização da banda nas plataformas.

## Publicação

Este projeto usa HTML, CSS e JavaScript puros e pode ser publicado diretamente pela Vercel CLI.
